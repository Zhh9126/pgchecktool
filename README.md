
# 🐘 PG Inspector – PostgreSQL 数据库健康检查工具

[![Python Version](https://img.shields.io/badge/python-3.6%2B-blue)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

**PG Inspector** 是一款功能强大的 PostgreSQL 数据库健康检查工具，支持单库深度巡检、批量并行检查、远程主机系统资源监控（通过 SSH），并可自动生成专业的 Word 和 Excel 报告。所有敏感密码均采用机器特征加密存储，保障配置安全。

## ✨ 核心特性

- 🔍 **单数据库检查**  
  全面收集数据库运行信息：版本、实例、表空间、连接、大表 TOP20、锁等待、慢查询、复制状态、索引使用率、缓存命中率、表膨胀、WAL 统计等。

- 🖥️ **远程主机资源监控**  
  通过 SSH 获取数据库所在主机的系统信息：CPU、内存、磁盘使用情况、负载等。

- 📊 **批量并行巡检**  
  基于 Excel 模板配置多个数据库，支持高并发检查（可控制并发数），自动汇总成功/失败列表，生成合并报告。

- 📄 **专业报告输出**  
  支持生成 Word（`.docx`）和 Excel（`.xlsx`）格式报告，内容结构化、图文清晰，便于归档和分享。

- 🔐 **密码安全存储**  
  密码采用 Fernet 对称加密，加密密钥基于运行机器的特征生成（主机名+系统版本），模板文件不可跨机器使用，提升安全性。

## 🚀 快速开始

### 1. 环境要求

- Python 3.6 或更高版本
- PostgreSQL 9.4 或更高版本（需有足够的查询权限）
- 远程主机检查需要 SSH 服务

### 2. 安装依赖

```bash
# 克隆项目
git clone https://github.com/yourusername/pg-inspector.git
cd pg-inspector

# 安装必需依赖
pip install psycopg2-binary cryptography paramiko openpyxl python-docx

# 或者使用 requirements.txt
pip install -r requirements.txt
```

> **提示**：`paramiko` 用于 SSH 远程检查，如不需要可忽略；`python-docx` 和 `openpyxl` 分别用于生成 Word 和 Excel 报告，可按需安装。

### 3. 运行程序

```bash
python pg_inspector.py
```

程序启动后将显示交互式菜单，按提示操作即可。

## 📖 使用指南

### 一、单数据库检查

1. 在主菜单中选择 `1. 单数据库检查`。
2. 依次输入数据库连接信息（主机、端口、数据库名、用户名、密码等）。
3. 选择是否包含 SSH 主机检查（如需检查远程主机系统资源，需提供 SSH 凭据）。
4. 检查完成后选择报告格式（Word/Excel/两者）。
5. 报告将自动保存在 `reports/` 目录下，可选择立即打开。

### 二、批量巡检（Excel 模板模式）

#### 2.1 生成 Excel 模板

- 进入主菜单 `2. 批量巡检` → `1. 生成 Excel 批量巡检模板`。
- 模板包含以下关键列：

| 列名       | 说明                                                   |
|------------|--------------------------------------------------------|
| 名称       | 数据库标识（用于报告文件名）                           |
| 主机IP     | 数据库 IP 或域名                                       |
| 端口       | PostgreSQL 端口（默认为 5432）                         |
| 数据库名   | 要检查的数据库名称                                     |
| 用户名     | 连接数据库的用户                                       |
| 密码       | 明文或加密后均可，程序自动处理加密                     |
| 包含主机检查 | `是`/`否` – 是否通过 SSH 检查主机资源                |
| SSH用户名  | 主机 SSH 用户名（如 `root`）                           |
| SSH密码    | 主机 SSH 密码（会自动加密）                            |
| SSH端口    | SSH 端口（默认 22）                                    |

> **注意**：模板中的密码会在首次使用时自动加密，且加密密钥与运行机器绑定，请勿将已加密的模板直接拷贝到其他机器使用。

#### 2.2 执行批量巡检

1. 编辑模板，填写待检查的数据库信息。
2. 在批量巡检菜单选择 `5. 执行批量巡检`，选择模板文件。
3. 设置并发数（建议 5~10）、超时时间等。
4. 程序将依次（或并行）检查每个数据库，并生成单个报告文件及汇总报告（JSON + Excel）。
5. 所有报告保存在 `batch_reports/巡检报告_时间戳/` 目录下。

### 三、模板安全操作

- **加密现有模板**：菜单 `批量巡检` → `3. 加密现有模板密码`，可将模板中的明文密码批量加密。
- **测试模板连接**：正式批量巡检前，可使用 `4. 测试模板连接` 快速验证所有数据库和 SSH 是否可达。

## 🛠️ 依赖库说明

|-------------------|-----------------------------------|--------------|
| `psycopg2-binary` | PostgreSQL 数据库连接             | ✅ 必需      |
| `cryptography`    | 密码加密/解密                     | ✅ 必需      |

| `python-docx`     | 生成 Word 报告                    | ⚠️ 如需 Word  |

## 📁 输出报告结构

### Word 报告
- 封面：检查对象、检查时间等基本信息
- 章节：
  - 系统信息（CPU/内存/磁盘，如有 SSH）
  - 实例信息
  - 数据库概览
  - 表空间、连接、大表 TOP20
  - 锁等待、慢查询
  - 复制、索引使用、缓存命中率
  - 表膨胀、WAL 统计

### Excel 报告
- **检查概览**工作表：列出所有检查项及记录数
- **基本信息**工作表：数据库连接参数
- 各类检查结果单独成表（如“连接信息”、“大表TOP20”等）

### 批量巡检汇总
- `批量巡检汇总报告.json`：包含成功/失败统计、各数据库报告路径
- `批量巡检汇总报告.xlsx`：易读的汇总表格

## ⚙️ 自定义与配置

- **并发线程数**：批量巡检时可通过参数 `max_workers` 调整（默认 5）。
- **超时时间**：支持自定义数据库连接和 SSH 超时（默认 30 秒）。
- **报告保存路径**：自动创建 `reports/`（单库）或 `batch_reports/`（批量）目录。

## 🔒 安全说明

- 所有密码（数据库密码、SSH 密码）在存储到 Excel 模板时均使用 **Fernet 对称加密**，加密密钥由运行机器的 **主机名 + 操作系统版本** 通过 PBKDF2 派生而来。
- 加密后的密码仅能在原机器上解密，即使模板文件泄露也无法直接获取明文。
- 生成的报告中**不会**包含任何密码信息。
- 建议定期更换数据库密码，并妥善保管模板文件。
